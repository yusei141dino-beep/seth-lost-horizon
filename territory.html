DATABASE / 003-A

TERRITORIAL STRUCTURE

セトの都市構造と六つの統治区画。

SET CITY / GENERAL RECORD

SET CITY

セトは旧サンフランシスコ湾岸地域を基盤として構築された大都市圏である。 2045年時点の登録人口は約4,800万人。都市は中央のグランド・パレスと、 その周囲に配置された五つの区画を中心に構成される。 その統治構造は、単なる地理的区分にとどまらず、 居住、産業、物流、治安、資本の配置と密接に結びついている。

DATABASE / 003-B

DISTRICT DATABASE

六つの統治区画と、それぞれに属する主要地域の記録。

DISTRICT / 01

GRAND PALACE

統治中枢・企業本部

セトの統治と企業権力が集中する中枢区画。 PleromaおよびEidolon Linkの制御に関わるPrism Tower、 高純度Sparksの供給拠点Fontを擁する。

DISTRICT / 02

RIDGEWAY

歓楽・娯楽・夜間経済

カジノ、ネオン、騒音、夜間経済によって特徴づけられる区画。 Belgrave、Kingswell、Westonなどの地域を含む。

DISTRICT / 03

BLACKROCK

工業・製造・重労働

工業施設と重工業的な都市機能が集中する区画。 Volcanus ForgeおよびAdamas関連施設を中心とし、 Harvick、Dunlow、Avaroなどの地域を含む。

DISTRICT / 04

LOXLEY

非合法経済・裏市場

ギャング勢力とブラックマーケットが存在感を持つ区画。 Crowley Yard、Knox、Ruston Brughなどの地域が位置する。

DISTRICT / 05

BAYSIDE

港湾・物流・対外接続

海上輸送と都市外部との接続を担う玄関口。 Port MerrinおよびCentral Pierを主要な港湾地域として持つ。

DISTRICT / 06

SANDWALL

戦災区域・封鎖地域

戦争による破壊の痕跡を残す、荒廃した封鎖区域。 登録人口は他区画と比較して極めて少なく、 North、South、East、Westの四区域によって区分される。

DATABASE / 003-C

ORGANIZATIONAL ARCHIVE

セトおよび企業管理社会の構造を形成する主要組織。

ORG / 001

CORPORATE GOVERNANCE

MONAD

仲裁機構から企業統治体制へ

1994年に仲裁機構として成立したMonadは、 2001年にPleroma主導の巨大企業体制へと移行した。 セトの成立と企業管理社会の形成を理解するうえで、 その制度的変遷は重要な記録となる。

EST. 1994 CORPORATE ORDER / 2001
ORG / 002

HIDDEN LEADERSHIP

PLEROMA

企業秩序の最上層

Pleromaは六人の人物によって構成される、秘匿された権力中枢である。 Monadの企業統治体制において重要な位置を占める。 Tetradの四責任者とは区別される存在であり、 両者を同一の組織構成として扱うことはできない。

CLASSIFIED SIX MEMBERS
ORG / 003

SECURITY / MILITARY

GUARDIANS

武装治安組織

セトの武装治安体制に属する組織。 その指揮系統と装備体系は、企業統治下における 治安維持および武力行使の構造を理解するための重要な記録である。
